# 理论笔记

grasp_grape 的技术笔记。每一篇都是「通用理论 + 它在这套代码里的落点」，
末尾的「在本项目里」给出具体文件、具体参数和实测数字。

写这些不是为了复述教科书。选材标准只有一条：**这个知识点在这个项目里真的付出过
代价或产生过判断**。所以每篇都带着实测数据和踩过的坑，包括那些走不通、已经排除的
方案——排除掉的路和走通的路一样值钱。

---

## 目录

### [01 · 关节控制与 PID](01-joint-control.md)
单关节动力学、PID 三项各自的作用与量级估算、位置接口与力矩接口的本质区别、
重力补偿、整定方法、容差为什么必须跟控制方式一起改、阻抗控制的前提。

> 核心一句：`SetPosition` 让机器人"看起来完美"——跟踪误差恒为零、关节无限刚性——
> 而力控、接触载荷、跟踪精度在那个模型里**根本不存在**。

### [02 · 运动规划](02-motion-planning.md)
任务空间 / 关节空间 / 自由空间、逆运动学的多解性、为什么用 RRT 而非 A*、
碰撞检查分辨率、笛卡尔路径、**路径与轨迹的区别**、时间参数化、规划请求适配器、
移动底座带来的额外维度。

> 核心一句：`compute_cartesian_path` 返回的是**路径不是轨迹**——不带时间戳，
> 直接执行会报成功而机械臂纹丝不动。本项目为此付出了 0.54 m 的末端误差。

### [03 · 碰撞检测与避障](03-collision-avoidance.md)
规划式与反应式的分工、规划场景的构成、什么该放进去什么不该、允许碰撞矩阵与
`touch_links` 的双向陷阱、碰撞检查的实现、SRDF 自碰撞、**接触在无限刚性关节上是
灾难**、事后验证、通往反应式避障的路。

> 核心一句：避障不只是"算一条不碰的路"，还包括"万一碰了会发生什么"——
> 后者由接触参数和关节刚度决定，和规划器无关。

### [04 · 移动底盘的控制](04-mobile-base-control.md)
滑移转向运动学、为什么轮式里程计不可信、车道保持的偏置平衡点陷阱、
**比例控制的末端塌陷**、到位判据不要要求做不到的事、单目 VIO 在地面车上的固有困难、
控制能力如何反过来约束任务设计。

> 核心一句：纯比例接近律在滑移转向上会让转向分量把内侧轮抵消到零，
> 车在原地打转永远走不完最后几厘米——这就是"底盘间歇性卡死"的真相。

## 一条贯穿全部四篇的经验

**没有定位根因之前不要调参数。**

本项目在这上面栽过不止一次：轨迹执行不动时去收紧控制器容差（越收越糟，因为轨迹
压根没在执行）；关节稳态误差大时去整体放大增益（更差，因为问题只出在手腕两个关节）；
底盘走不到位时怀疑被障碍卡住（其实是被指令成了原地转向）。

有效的做法是先**测出能区分假设的量**：轨迹执行不动就写最小复现、关节误差就逐关节
打印、底盘不动就同时打印指令/真值速度/轮速。每一次这样做，答案都在一次实验内出现。
